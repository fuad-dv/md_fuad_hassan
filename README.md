# MD Fuad Hassan Shiraji: Portfolio

Personal portfolio built with plain HTML, CSS and JavaScript. Parrot-green glass UI with a 3D background (three.js).

Live: https://fuad-hassan-shiraji.netlify.app/

## Files
- `index.html`: the whole site
- `resume.pdf` and `cv.pdf`: shown by the "Click to view resume" and "Click to view CV" buttons (they open on the site)
- `assets/`: profile photo, project screenshots, favicon and `og.jpg` (the link preview image)

## Update the resume
Replace `resume.pdf` or `cv.pdf` with the new file (same name) and commit.

## Contact form
Messages go through Formspree (`https://formspree.io/f/mqppppnk`) to the email on the Formspree account.

## Run locally
Use a local server so the PDF viewer works, e.g. `python -m http.server`, then open http://localhost:8000.
