# MD Fuad Hassan Shiraji: Portfolio

Personal portfolio built with plain HTML, CSS and JavaScript. Parrot-green glass UI with a 3D background (three.js).

Live: https://fuad-dv.github.io/portfolio/

## Files
- `index.html`: the whole site
- `resume.pdf`: resume shown by the "Click to view resume" button (opens on the site)
- `assets/photo.jpg`: profile photo

## Update the resume
Replace `resume.pdf` with the new file (same name) and commit.

## Run locally
Use a local server so the resume viewer works, e.g. `python -m http.server`, then open http://localhost:8000.
